# DSS white-base model library
Clean white garments on models, the source for every recolor. Meta makes only the white; other colors come from `recolor.py`.

Codes: `KB` kid boy, `KG` kid girl, `M` man, `W` woman, `D` dog. Views: FRONT, BACK, SIDE, WALK, TORSO.
Files live in `white-base/` (native resolution, JPEG q95). `white-base/INDEX.csv` lists every code and flags the ones whose code was inferred because the image had no caption.

Missing: M-HOODIE-FRONT, KB-TEE-FRONT, KG-TEE-FRONT (only chat screenshots exist, need the original files), kid hoodies, dog tee back/side.
