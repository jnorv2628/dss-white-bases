# blanks/white
White flat-lay blanks from the Meta library, one garment per file, named BLANK-<W|M|DOG>-<STYLE>-WHITE[-BACK]-vN.
- Source images carry a baked-in caption (bottom-left). `clean/` holds caption-removed copies; use those for anything customer-facing.
- Colors come from `recolor.py`, never from Meta. Flat-print designs use `compose.py`.
- Off-system backdrops (paper-fleck / linen) on a few early women's booty/panty short frames: regenerate for uniformity.
- Files marked "cropped from phone screenshot" in INDEX.csv are low-res; regenerate before site use.
- Batch 8-9 additions: men's shoe blanks (SNEAKERLOW, BOOTLACE, LOAFERSOFT, COURTLOW, SNEAKERCOURT), dog beds (BOLSTER, SHERPA, CANOPY), bags (TOTE, PETIT, WEEKENDER, CARRIER, TREAT) and dog hardware (COLLAR, LEASH, HARNESS). Several source captions were wrong (a boot back captioned as the pair, a sneaker captioned LOAFERSOFT); filenames follow what the image actually shows and INDEX.csv notes the original caption.
- Hardware is gold (collar, leash, harness, petit, weekender) or silver (carrier, treat pouch): pick one metal across the dog set before production.
